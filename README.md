# David Chilengwa Portfolio
All files are in this one folder (no subfolders).
Pages: index.html, about.html, projects.html, contact.html. Styles: style.css. Scripts: script.js.
Files: logo.png, profile.jpg, david-chilengwa-cv.pdf, cv-thumb.jpg, business-promotional-flyer.jpg.
Add projects: new entries in the FLYERS list at the top of script.js (image file in this folder).
Run locally: python3 -m http.server here, open http://localhost:8000.
Publish: upload this folder to Netlify Drop, GitHub Pages or Cloudflare Pages.
